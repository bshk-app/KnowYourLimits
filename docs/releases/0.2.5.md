# 0.2.5 — Индикаторы квот в трее Windows

У Claude и Codex отдельные иконки с кольцом остатка квоты и символом провайдера.
Остаток виден без открытия панели. При системном цвете кольцо становится жёлтым
при остатке до 20% и красным до 5%. Пользовательский цвет, символ и размер
применяются из настроек, отключённый счётчик скрывает соответствующую иконку.

Исторические данные отображаются пунктиром и знаком `~` в подсказке. Неизвестная
квота показывается серым пунктирным кольцом. Нажатие на любую иконку открывает
общую панель рядом с ней; повторное нажатие закрывает панель.

Повторный запуск открывает панель уже работающего экземпляра. Эта защита общая
для установленной и отдельной версии приложения.

Windows 10/11 x64; установщик пока без Authenticode. Нативные уведомления
доступны только на macOS. Автозапуск и автоматические обновления не реализованы.
