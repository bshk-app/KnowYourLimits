# 0.2.5 — quota indicators in the Windows tray

Claude and Codex have separate icons with remaining quota rings and provider
symbols. Remaining quota is visible without opening the panel. With system color,
the ring becomes yellow at or below 20% remaining and red at or below 5%. Custom
color, symbol, and size follow settings; disabling a counter hides its icon.

Historical data uses dashed rings and `~` in tooltips. Unknown quota uses a gray
dashed ring. Clicking either icon opens the shared panel beside it; clicking
again closes the panel.

Launching again opens the existing instance's panel. Installed and portable
versions share this protection.

Windows 10/11 x64; the installer currently has no Authenticode signature. Native
notifications are macOS-only. Automatic startup and updates are not implemented.
