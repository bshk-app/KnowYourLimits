# 0.2.10 — Compact menu bar indicator

- The macOS menu bar indicator now fits its content, with minimal space beside neighboring icons in every layout.
- A reading in progress only dims the value. The indicator no longer adds `~` or changes width during an update, and the shown percentage stays the same until the update ends.
- `~` still marks values that are out of date, so the indicator can change width when a value becomes stale or the number of digits changes.
- The settings preview matches the menu bar indicator.
