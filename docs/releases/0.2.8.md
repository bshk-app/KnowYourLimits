# 0.2.8 — Newer Claude Code versions

- Claude readings work with Claude Code 2.1.296 and newer. Earlier builds accepted only 2.1.296, so an automatic Claude Code update stopped readings and asked for a version older than the installed one.
- Claude Code versions older than 2.1.296 are still rejected; the message now asks for 2.1.296 or newer.
- If a newer Claude Code changes its undocumented usage response, the panel shows the reading as unavailable or failed, never as guessed percentages.
- Homebrew publication installs the tap before its audit.
