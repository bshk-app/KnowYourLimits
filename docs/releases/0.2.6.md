# 0.2.6 — Contrasting icons for Windows themes

The Claude and Codex icons follow the Windows taskbar theme, even when the app
theme differs. On a dark taskbar, symbols are white and rings use light colors;
on a light taskbar, symbols are dark and rings use more saturated dark colors.
Theme changes apply within five seconds without restarting the application.

Symbols and rings are thicker. Historical data still uses dashed rings and the
`~` prefix in tooltips, but the icons are no longer dimmed. Low quota warnings
and custom ring colors are preserved.
