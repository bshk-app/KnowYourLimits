# 0.2.6 — Контрастные иконки для тем Windows

Иконки Claude и Codex следуют теме панели задач Windows, даже если тема
приложений отличается. На тёмной панели символы белые, кольца светлые; на
светлой символы тёмные, кольца используют более насыщенные тёмные цвета.
Переключение темы применяется без перезапуска, в течение пяти секунд.

Символы и кольца стали толще. Исторические данные по-прежнему отмечены
пунктиром и знаком `~` в подсказке, но больше не затемняют иконку.
Предупреждения о низком остатке и пользовательский цвет кольца сохраняются.
