# 0.2.4 — KnowYourLimits для macOS

Индикатор квот Claude и Codex в строке меню macOS.

- Отдельное окно настроек с вкладками строки меню и каждого провайдера.
- Три вида индикатора: один ряд, два ряда и кольца.
- Сохранение последних квот между запусками с явной отметкой устаревших данных.
- Ручное и фоновое обновление, локальные уведомления и отмена чтения.
- Интерфейс на 25 языках: русский, английский и остальные официальные языки ЕС.
- Повторный клик по индикатору закрывает открытую панель.

Требования: macOS 13+ на Apple Silicon и авторизованный официальный CLI
нужного провайдера. Claude Code: версия 2.1.296.

Авторизация остаётся в официальных CLI. Приложение не читает файлы с токенами
или cookies. При ответе Claude 429 резервное чтение использует минимальный
запрос к Haiku через CLI; такой запрос может расходовать кредит Agent SDK.
Подробности — в README.

Автозапуск и автоматическая установка обновлений пока не реализованы.
Нативные клики по окну настроек и панели требуют ручной проверки на macOS.
