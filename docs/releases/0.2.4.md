# 0.2.4 — KnowYourLimits for macOS

A Claude and Codex quota indicator in the macOS menu bar.

- Separate settings window with menu bar and provider tabs.
- Three indicator layouts: one row, two rows, and rings.
- Latest quotas persist between launches with explicit stale data labels.
- Manual/background refresh, local notifications, and cancellation.
- Interface in 25 languages: Russian, English, and the remaining official EU languages.
- Clicking an indicator again closes the open panel.

Requirements: macOS 13+ on Apple Silicon and the authenticated official CLI for
the selected provider. Claude Code version: 2.1.296.

Official CLIs retain authorization. The application does not read token or cookie
files. After Claude HTTP 429 responses, fallback readings use a minimal Haiku
request through the CLI, which may spend Agent SDK credit. See README for details.

Automatic startup and automatic update installation are not implemented.
Native settings/panel clicks require manual macOS verification.
