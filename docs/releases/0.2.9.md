# 0.2.9 — Accurate Codex quota states

- Codex no longer asks you to sign in again just because usage is blocked, a quota window has expired, or a reading fails.
- Fresh Codex quota measurements remain visible when usage is blocked. Fully used windows show **Limit reached**; a block with quota remaining shows **Usage blocked**.
- Old percentages are labeled **Previous value** beside the number, so they cannot be mistaken for current remaining quota.
- Blocked readings remain excluded from quota recovery notifications.
