# 0.2.7 — Signed updates and distribution

- Check for stable app updates from the quota panel, download a verified update, and explicitly install and restart.
- Downloaded updates use version-bound Minisign signatures on macOS and Windows. The macOS app and DMG also retain Developer ID signing, notarization, and stapling.
- Publish one verified release to GitHub Releases, the `bshk-app/tap/knowyourlimits` Homebrew cask, and Zamok's stable updater channel.
- Promote existing draft files without rebuilding or replacing a published release.
- Keep quota readers independent of update checks and finish active CLI cleanup before installation.

Windows installers and portable executables still lack an Authenticode publisher signature. The portable executable is intended for manual replacement; use the installed application for managed updates.

The README now includes real native screenshots and a Cap tutorial edited with HyperFrames.
