# 0.2.4 — нативный дизайн и окно настроек

Интерфейс перенесён из проекта KnowYourLimits в Claude Design
(«Сделай дизайн максимально похожий на native app»).

- **Настройки — отдельное окно** с вкладками «Строка меню · Claude · Codex»
  (`settings.html`, `src/settings.ts`). Открывается пунктом «Настройки… ⌘,»
  в панели и шестерёнкой карточки сразу на вкладке её провайдера. Открытое окно
  сохраняет черновик и только переключает вкладку (событие `settings-tab`).
  Высота окна следует содержимому. ⌘W и «Отменить» закрывают окно без сохранения.
  Интервал обновления по-прежнему применяется сразу.
- **Панель:** системные серые, плитка с иконкой провайдера, статус точкой,
  крупное «осталось», шестерёнка. Шкала окна с просечками порогов, подвал карточки
  «Снимок · 2 мин назад · авто 5 мин» и «Обновить». Во время чтения та же кнопка
  отменяет обновление. Цвет числа следует худшему непросроченному окну.
- **Контролы AppKit:** сегменты (иконка, размер, цвет), NSSwitch, pop-up.
- Отличия от макета: при устаревших данных остаётся последний процент
  «по снимку»; бейдж «Прошлый снимок» нейтральный; окно панели непрозрачное.

## Native

`open_settings` — синхронная команда: Tauri выполняет её на главном потоке,
поиск и создание окна не пересекаются. Окно `settings` с `TitleBarStyle::Overlay`,
скрытым заголовком и drag region в тулбаре. Скрытие по потере фокуса и
`CloseRequested → hide` относятся только к панели `main`; окно настроек
закрывается по-настоящему. Capability `settings`: события, перетаскивание,
`set_size`, `close`; у панели этих прав нет (тест `permissions_tests`).

## Повторный клик по строке меню (пересборка 0.2.4)

Левый клик переключает панель: открывает скрытую, скрывает открытую.
Состояние берётся при нажатии кнопки мыши, действие выполняется при отпускании:
потеря фокуса между этими событиями не превращает закрытие в повторное открытие.
Если AppKit снимает фокус ещё до обработчика нажатия, нажатие над нашей иконкой
проверяется через `NSEvent` и рамку окна status item в общих экранных координатах.
Escape, клик вне панели и переключение приложений по-прежнему скрывают панель;
правый клик открывает существующее меню, окно настроек не меняется.

Rust: 124 теста библиотеки и 2 теста примеров, Clippy `-D warnings`, fmt;
TypeScript и production Tauri build прошли. Физические клики автоматизацией
не подтверждены: CUA не получает AX-состояние приложения (`timeoutReached`).

Обновлённая локальная копия подписана Developer ID Q8H6GWJ658, hardened runtime
и timestamp; `codesign --verify --strict --deep` пройден. Профиль `notarize`
по-прежнему отсутствует, новая нотаризация и DMG не создавались.
Настройки сохранены без изменения. Предыдущая копия:
`~/Library/Caches/KnowYourLimits/app-backups/KnowYourLimits-0.2.4-before-tray-toggle-1791744807637.app`.
SHA-256 установленного бинарника:
`01e4fcfb821f5856295c9e3ec78101da6c68e809a0769b8caafde929b2f7bf74`.

## Высота панели по содержимому (пересборка 0.2.4)

Окно панели было всегда 620 pt, под «Настройками» оставалась пустота. Теперь
`ResizeObserver` сообщает высоту `.kyl-panel`, команда `fit_panel` меняет размер
окна (360 pt по ширине, не ниже 160 pt и не выше рабочей области экрана) и
возвращает прежнюю позицию, чтобы верх остался под иконкой. `show_panel`
ограничивает позицию по текущей высоте окна. Тесты: `panel_height` (Rust) и
e2e «panel window follows its content height». Rust 125, TS 55, Playwright 30
(+1 тест локализации с жёстким `http://127.0.0.1:1420` не запускается по `file://`).
Переустановлено (PID 96880, SHA-256
`f16be385241e1029fdd358bbf41415084daa6bf7b30f866ea0408af37eab32cb`), прошлая копия
`app-backups/KnowYourLimits-0.2.4-before-panel-fit-*.app`.
