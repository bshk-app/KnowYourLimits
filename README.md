# KnowYourLimits

Индикатор квот Claude и Codex в строке меню macOS и трее Windows. Версия **0.2.6**.

[Скачать Windows-версию](https://github.com/bshk-app/KnowYourLimits/releases/latest):
установщик для текущего пользователя или отдельный EXE без установки.
Релизы собираются в GitHub Actions; рядом с файлами опубликованы SHA-256.

У каждого провайдера есть собственная кнопка подключения и ручного обновления.
При первом запуске счётчики пустые. После чтения квоты приложение сохраняет
последние снимки, время измерения и подключённые провайдеры между запусками.
Демо и вымышленных квот нет. Настройки провайдеров также сохраняются.

В строке меню показывается **остаток**, минимум среди основных окон.
В карточках — **использовано**, отдельно для каждого окна. Прошлый снимок остаётся
виден с отметкой `~` в строке меню и «Данные устарели» в карточке. Возраст и время
измерения не меняются при ошибке или перезапуске. `—` означает отсутствие
измерения или выход из аккаунта. Истечение времени сброса не создаёт новую квоту.
При обновлении значения сохраняются до получения следующего снимка.

## Язык интерфейса

В **Настройки → Строка меню → Язык** можно выбрать язык системы или один из 25 языков:
английский, русский и все 24 официальных языка ЕС (английский входит в их число).
Выбор применяется кнопкой «Сохранить», сохраняется после перезапуска и обновляет
открытые окна, меню macOS и уведомления. Для неподдерживаемого системного языка
используется английский. Время, числа и проценты форматируются по выбранной локали.

Словари находятся в `src/locales/*.json`; они общие для TypeScript и Rust.
Проверки покрывают полноту ключей, параметры переводов, миграцию старых настроек
и размещение всех языков в панели и настройках.

## Подключение

- **Codex:** установленный и авторизованный официальный CLI → «Подключить Codex».
  Затем «Обновить Codex» в карточке или меню иконки.
- **Claude:** установленный Claude Code **2.1.296** → «Подключить Claude».
  При отсутствии авторизации появляется **«Войти в Claude»**. Кнопка запускает
  официальный `claude auth login --claudeai`; CLI открывает страницу в браузере.
  Вход завершается пользователем, затем приложение читает квоту автоматически.
  Вход и чтение можно отменить; выход приложения также ожидает завершения CLI.

CLI находят в `/opt/homebrew/bin`, `/usr/local/bin`, затем `~/.bun/bin`,
`~/.local/bin`, `~/.npm-global/bin`, `~/.volta/bin`, `/usr/bin`.
Поиск не исполняет shell/profile и не зависит от каталога запуска.

Авторизацию, запросы и хранение токенов выполняют официальные CLI.
Приложение не открывает credential-файлы или cookies.
Claude читает структурированные данные `/usage` через control request `get_usage`
(stream-json, без prompt); текстовые проценты не используются как запасной источник. Пустой machine report означает недоступную квоту.
Если usage endpoint отвечает 429, приложение делает один минимальный запрос к Haiku
через тот же CLI и берёт окна 5 часов/неделя из rate-limit заголовков ответа
(~$0.0001 за чтение; `claude -p` расходует кредит Agent SDK, а не лимиты плана).
Если заголовков нет, остаётся пауза до повтора. Пока действует 429, чтение сразу
идёт через этот запрос. CLI кэширует его prompt на час, поэтому повторы стоят ~$0.00001.
Поддержка pinned CLI не является гарантией стабильности его недокументированного
машинного формата. [Подробности и ограничения](docs/claude-spike.md).

Настройки открываются отдельным окном с вкладками **Строка меню · Claude · Codex**:
пунктом «Настройки… ⌘,» в панели или шестерёнкой карточки, сразу на вкладке её
провайдера. Во вкладке «Строка меню» три вида: **Один ряд**, **Два ряда**, **Кольца**.
У Claude и Codex отдельно выбираются иконка, цвет, размер, интервал обновления,
уведомления, звук и предупреждение о восстановлении. Обычный текст не выделяется;
поля редактируются. Интерфейс следует проекту KnowYourLimits в Claude Design.

Таймер можно выключить, выбрать 1, 2, 5, 10, 15, 30, 60 минут или **Авто**:
каждые 5 минут, если панель открывали в последние 30 минут, иначе каждые 15,
как у Claude Desktop. Повторное чтение в течение минуты после успеха или 20 секунд
после ошибки не запускает CLI и показывает последнее значение. Таймер работает
в фоне после подключения аккаунта, включая закрытую панель. Выбор интервала
применяется и сохраняется сразу, отдельное нажатие «Сохранить» не требуется.
Карточка показывает время обновления; интервал виден в настройках. При ошибке записи выбор возвращается
к сохранённому значению, рядом появляется сообщение. Остальные настройки
применяются кнопкой «Сохранить». Новые настройки
и старые пороги сохраняются. После перезапуска подключения и последний снимок
восстанавливаются с диска, а таймер возобновляется после выбранного интервала.
Само чтение кэша не запускает CLI и не отправляет уведомления.
По умолчанию таймеры и уведомления выключены; при включении уведомлений macOS
запрашивает разрешение. Кнопка проверки отправляет локальное уведомление.
Предупреждения не повторяются на каждом обновлении той же квоты.
При ограничении частоты запросов Claude панель показывает паузу и срок повтора;
повторные клики и таймер не запрашивают endpoint раньше этого срока.
Последний реальный снимок и пауза переживают перезапуск. Ошибка записи на диск
показывается в панели; актуальное значение остаётся в памяти.

Автозапуск пока не реализован. Снимки старше 5 минут считаются устаревшими,
даже при выборе большего интервала, но проценты продолжают отображаться как
последнее известное значение. Уведомления используют только свежие чтения.

## Установка и сборка

### Windows

Windows 10/11 x64. Для разработки нужны Visual Studio Build Tools с workload
«Desktop development with C++», Rust 1.90+, Bun и WebView2 Runtime.

```powershell
bun install --frozen-lockfile
bun run tauri dev
bun run package:windows
```

Сборка создаёт установщик `KnowYourLimits-0.2.6-windows-x64-setup.exe`, отдельный
`KnowYourLimits-0.2.6-windows-x64.exe` и `manifest.json` с SHA-256 в
`artifacts/windows/0.2.6/`. Установщик работает для текущего пользователя и
при необходимости устанавливает WebView2. Сборка пока без подписи Authenticode.
GitHub Actions также собирает установщик и сохраняет его как артефакт.

В Windows у Claude и Codex отдельные иконки с кольцом остатка квоты.
Символы белые на тёмной панели задач и тёмные на светлой; палитра колец также
подстраивается под режим Windows, отдельно от темы приложений. Изменение темы
применяется без перезапуска, в течение пяти секунд. Устаревшие данные сохраняют
яркость символа и кольца, отличаясь пунктиром.
При системном цвете остаток до 20% отмечается жёлтым, до 5% — красным;
свой цвет кольца применяется из настроек. Исторические данные показываются пунктиром
и знаком `~` в подсказке, неизвестная квота — серым пунктирным кольцом.
Выбор провайдеров, символа, цвета и размера применяется к иконкам.
Проценты видны в подсказке
иконки и панели. CLI ищутся в `~/.local/bin`, `~/.bun/bin`, `~/.cargo/bin`,
`%APPDATA%/npm`, WinGet Links, каталоге Node.js и абсолютных каталогах `PATH`.
Поддерживаются нативные `.exe` и официальные npm-установки Claude/Codex с Node.js.
Для npm запускается JS entry point напрямую, без исполнения `.cmd` через shell.
CLI используют свою авторизацию Windows; вход, выполненный только в WSL,
не подключает Windows CLI автоматически. Версия Claude остаётся **2.1.296**.

Настройки и кэш хранятся в `%APPDATA%/dev.knowyourlimits.desktop/`.
Системный язык Windows применяется к нативному меню. При отмене и выходе
приложение завершает CLI и дочерние процессы через Windows Job Object.
Нативные уведомления и три вида компоновки строки меню реализованы для macOS;
на Windows используются квадратные кольцевые индикаторы. Автозапуска пока нет.
Приложение работает в одном экземпляре: повторный запуск установленной или
отдельной версии открывает панель уже работающего приложения.

### macOS

macOS 13+, Apple Silicon. Публичная сборка подписывается Developer ID через
**Zamok** и нотарифицируется Apple. Подготовка 0.2.4 пока не завершена:
профиль нотаризации `notarize` отсутствует, готового DMG 0.2.4 нет.
После успешной упаковки DMG и `manifest.json` появятся в `artifacts/macos/0.2.4/`.
[Подготовка и публикация на GitHub](docs/publishing.md).

Для разработки нужны Xcode Command Line Tools, Rust 1.90+ и Bun:

```sh
bun install --frozen-lockfile
bun run tauri dev
```

Левый клик по иконке открывает панель, повторный скрывает её.
Escape или потеря фокуса также скрывает панель.
Правый клик открывает меню обновления и выхода.

```sh
bun run package:macos
```

Команда проверяет доступ к нотаризации, собирает Tauri `.app`, затем запускает
`zamokctl package` с Developer ID и существующим Keychain-профилем `notarize`
либо ключом App Store Connect. Публичные параметры подписи находятся
в `packaging/macos.json`. Распространяется результат Zamok, а не неподписанный
Tauri bundle из `src-tauri/target/release/bundle`.

Browser preview использует тот же интерфейс с пустыми квотами. Подключение
аккаунтов доступно только в нативном приложении.
Native settings: `~/Library/Application Support/dev.knowyourlimits.desktop/settings.json`.
Последние нормализованные квоты и подключения: `quota-cache.json` в том же
каталоге. Запись атомарная, права0600; токенов, cookies и CLI logs в файле нет.
Browser settings хранятся отдельно в localStorage.

## Проверки

```sh
bun run test
bun run test:release
bun run check:release
bun run typecheck
bun run check
bun run build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --locked --manifest-path src-tauri/Cargo.toml --all-targets
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
bun run test:e2e
```

Синтетические subprocess-тесты используют `/usr/bin/python3`; он не нужен для
работы приложения. Default tests не запускают реальные CLI или вход.
Playwright проверяет UI с mock IPC; нативный Tauri ACL проверяется через реальное
`RuntimeAuthority`. Это не заменяет проверку физического окна macOS.

Явное чтение через тот же coordinator и поиск CLI, что используются в приложении:

```sh
cargo run --locked --manifest-path src-tauri/Cargo.toml --example live_read -- --live
cargo run --locked --manifest-path src-tauri/Cargo.toml --example live_read -- --live claude
```

Smoke не запускает вход и выводит только нормализованное состояние.
`--persist` в конце команды дополнительно читает и сохраняет кэш приложения;
используйте его при закрытом приложении.
